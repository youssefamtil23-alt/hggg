# Blocky Boost League

A tiny browser game mashing up car soccer and a block-built world. Drive the blue voxel car, hit the ball into the orange goal, and use boost to get there faster.

## Play

Open `index.html` in a modern browser. No build step or dependencies are required.

- **WASD** or **arrow keys**: drive and steer
- **Space**: boost while accelerating
- **R**: reset the match

Blue scores in the right-hand goal; orange scores in the left-hand goal. The game is a small, single-player arcade prototype.
